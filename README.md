# Лабораторная работа №2 — Авиарейс (Flight)

## Этап №1. Определение сущности

### Что представляет собой объект?
Авиарейс — конкретный рейс, выполняемый авиакомпанией
по определённому маршруту в определённое время.

### Какие данные характеризуют объект?
- Номер рейса
- Пункт вылета
- Пункт назначения
- Время вылета
- Тип самолёта (enum)
- Общее количество мест
- Количество занятых мест

### Какие действия можно выполнять с объектом?
- Продать билет
- Вернуть билет
- Изменить статус рейса
- Отменить рейс
- Получить процент загрузки

### Какие состояния объекта недопустимы?
1. Отрицательное количество занятых мест
2. Занятых мест больше, чем всего
3. Общее количество мест <= 0
4. Пустой номер рейса
5. Пункт вылета совпадает с пунктом назначения
